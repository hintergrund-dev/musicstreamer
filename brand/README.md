## The mark

A ring cut into three arcs of 60, 30 and 10 percent: one listener's month, split among the artists
they played. It also reads as a record. The mark always sits on its raspberry tile, so it works on
any background.

| File | Use |
|---|---|
| `mark.svg` | app icon, favicon, avatar |
| `logo-light.svg` | mark and wordmark on light backgrounds |
| `logo-dark.svg` | mark and wordmark on dark backgrounds |

Keep clear space of half the tile's width around the logo. Do not recolour the tile, rotate the
ring or change the arc proportions.

## Colour

| Role | Light | Dark |
|---|---|---|
| Raspberry (accent, tile) | `#C8234F` | `#FF7096` (accent on dark; the tile stays `#C8234F`) |
| Ink / text | `#1E1418` | `#F3EAED` |
| Paper / background | `#FBF8F9` | `#171114` |
| Muted text | `#6F6268` | `#B3A3A9` |
| Line | `#E0D3D8` | `#46383E` |
| Box | `#F4ECEF` | `#231A1E` |

Raspberry is the only colour. Neutrals lean slightly towards it. Use the accent for links, the
`.eu` in the wordmark and one highlight per diagram.

## Type

- **Display:** Instrument Serif, regular, for the wordmark and headings. Set large and tight.
- **Text:** the system sans-serif stack.

Instrument Serif is licensed under the SIL Open Font License and is self-hosted on the site; the
wordmark in the logo files is outlined, so the files need no font.
